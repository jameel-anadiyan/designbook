# UI rules

- SWA Diamonds: white + teal only. Light theme only (`color-scheme: light`), never use `dark:` classes,
  ignore OS dark mode.
- No black or dark backgrounds anywhere — including lightbox, video player, camera scanner, modals.
  Overlays are white at 90% (`bg-white/90`) with a blur, never a dark scrim.
- Tokens: teal-50 `#F4FAFA`, teal-100 `#E6F3F4`, teal-600 `#00737D` (primary), teal-700 `#005A62`,
  teal-800 `#0E4B52` (body text, never black), line `#D5E8EA`.
  Status tints (small badges only): hold `#FFF4E0/#8A5A00`, error `#FDECEC/#A12B2B`,
  sold `#EEF1F2/#4A6366`.
- Fonts: headings Cormorant Garamond 600; UI Jost 400/500. Uppercase labels with `tracking-[0.12em]`.
  Prices: tabular numerals.
- Mobile-first. < 640 px bottom tab bar + floating Upload; 640–1023 icon rail; ≥ 1024 labelled sidebar.
- Touch targets ≥ 44 px; respect safe areas. Transitions 150–200 ms. Skeletons in teal-50.
- Gallery views: Grid (1–4), List, Lookbook, Customer Showcase, Slideshow, Compare + Shortlist.
- Every interactive element gets a unique, descriptive `id`.
